## 禁止双指放大
[`user-scalable`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Guides/Viewport_meta_element#user-scalable)

控制是否允许页面上的放大和缩小操作。有效值为 `0`、`1`、`yes` 或 `no`。默认值为 `1`，与 `yes` 相同。将值设置为 `0`（即与 `no` 相同）将违反 Web 内容无障碍指南（WCAG）。
```html
<meta name="viewport" content="user-scalable=0"/>
```

## 禁止缩放
[`minimum-scale`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Guides/Viewport_meta_element#minimum-scale)

控制页面允许缩小的倍数。最小值是 `0.1`。最大值是 `10`。默认值为 `1`。负值会被忽略。

[`maximum-scale`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Guides/Viewport_meta_element#maximum-scale)

控制页面允许放大的倍数。设置一个低于 `3` 的值将不具备无障碍访问性。最小值是 `0.1`。最大值是 `10`。默认值为 `1`。负值会被忽略。

```html
<meta name="viewport" content="minimum-scale=1,maximum-scale=1">
```
